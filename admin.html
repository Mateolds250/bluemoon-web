¿Cómo creo el token de acceso? (una sola vez)
  1. Entra a github.com/settings/personal-access-tokens/new (inicia sesión si te lo pide).
  2. Token name: escribe algo como "BlueMoon Admin".
  3. Expiration: elige la opción más larga disponible.
  4. Repository access: selecciona "Only select repositories" y elige bluemoon-web.
  5. Permissions → despliega "Repository permissions" → busca Contents → cámbialo a Read and write.
  6. Baja y haz clic en Generate token.
  7. Copia el token que aparece (empieza con github_pat_) y pégalo arriba en el campo "Token de acceso de GitHub".

Si alguna vez pierdes el token o quieres invalidarlo, entra a la misma página de GitHub y bórralo — el sitio sigue funcionando igual, solo dejarías de poder publicar cambios hasta crear uno nuevo.
